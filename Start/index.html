Codenix Ecosystem Privacy Policy

Official Document: /policy/

1. Introduction & Scope

Welcome to Codenix ID (/policy/). This document governs authentication, virtual identity reservation (`username@codenix`), TOTP multi-factor authentication, and Codenix MGO (Magic Click-Grid) pattern protocols across all services.

2. Identity & Data Encryption

All sensitive authentication credentials, TOTP seeds, API keys, and MGO click signatures are stored with military-grade AES-256 encryption. We enforce zero-knowledge hashing on standard credentials.

3. Virtual Handle & MGO Usage

Your Virtual Codenix ID (`username@codenix`) acts as your public identifier. Codenix MGO allows secure login using a custom click-count pattern and secret letter without entering passwords or TOTP codes.

4. Multi-Factor Authentication Compliance

To access executive sandbox environments, users are required to enroll in TOTP-based Multi-Factor Authentication (MFA) or configure an MGO profile.
