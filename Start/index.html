Codenix Ecosystem Privacy Policy

Official Document: /policy/

1. Introduction & Scope

Welcome to Codenix ID (/policy/). This document governs the authentication, data handling, virtual identity reservation (`username@codenix`), and multi-factor authentication procedures across all Codenix AI services, neural tools, and web arcade leaderboards.

2. Identity & Data Encryption

All sensitive authentication credentials, TOTP seeds, and API keys are stored with military-grade AES-256 encryption. We enforce zero-knowledge hashing on standard credentials and restrict access strictly to authorized session tokens.

3. Virtual Handle Usage

Your Virtual Codenix ID (`username@codenix`) acts as your public identifier across all developer platforms and sandboxes. You retain rights to your generated code and projects while adhering to community fair-use standards.

4. Multi-Factor Authentication Compliance

To access executive sandbox environments and token key generation, users are required to enroll in TOTP-based Multi-Factor Authentication (MFA). Verification codes rotate every 30 seconds according to RFC 6238 specifications.
