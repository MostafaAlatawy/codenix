Cloudflare Pages & Supabase OAuth 2.1 Setup Guide

1 Routing /oauth/consent on Cloudflare Pages

Cloudflare Pages automatically serves index.html for unknown routes (SPA fallback) as long as no custom 404.html overrides it. For explicit direct routing and clean headers, deploy index.html (alongside logo.png and a _redirects file containing /oauth/consent /index.html 200) to your Cloudflare Pages project root.

2 Supabase OAuth Server & URL Configuration

  • Enable OAuth 2.1 Server: In your Supabase Dashboard (rnlwrngfgvznndlekmrz), navigate to Authentication → OAuth Server and enable the OAuth 2.1 provider.
  • Authorization Path: Set the Authorization URL / Consent Path to: https://codenix.pages.dev/oauth/consent
  • Redirect URLs: Under Authentication → URL Configuration, set Site URL to https://codenix.pages.dev and add https://codenix.pages.dev/oauth/consent to Additional Redirect URLs.
